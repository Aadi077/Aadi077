### 🚀 Projects

**[Gametime.api](https://github.com/Aadi077)** — Real-Time Sports Analytics & AI API
Node.js/Fastify API with 8 REST endpoints and a WebSocket stream delivering NBA and soccer updates at 4–6s average freshness. Play-by-play pipeline normalizes, dedupes, and streams live game state plus AI-generated narration. Shipped a typed SDK to npm as `gametime-api-client`.

**MGC Futures Trading Bot** — Automated Micro Gold Strategy
Rules-based intraday system on TopstepX with programmatic entry, exit, and position risk management. ICT signal logic including Inverted Fair Value Gap detection, with separate models tuned for NY and London sessions. Net profitable across 190 trades over 4 months live, 9% max drawdown.

**GridGuard AI** — Power Grid Monitoring & Defense
AI dashboard monitoring U.S. grid infrastructure in real time, simulating equipment failures and cyber attacks to generate anomaly scenarios. Detection models flag threats, assign risk levels, and recommend mitigations. Presented to Sandia National Laboratories.
